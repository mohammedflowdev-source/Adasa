# عدسة - عالم التصوير الفوتوغرافي

منصة ومدونة متخصصة في فن التصوير الفوتوغرافي، تقدم أسرار المحترفين ونصائح عملية ومقالات تعليمية متكاملة.

## التقنيات المستخدمة

- React 19
- React Router 7
- Tailwind CSS 4
- Vite

## التشغيل محلياً

```bash
npm install
npm run dev
```

## بناء المشروع

```bash
npm run build
```
